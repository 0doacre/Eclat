# Les Collines Vertes — découvertes v1

Trois illustrations pour les explorations existantes : les Rails Rouillés / le Wagonnet, la Vue du Sommet et le Replat. Le paysage de collines déjà dans le jeu reste la référence de relief et de palette : herbes olive et ocre, roches claires striées de vert et de sombre.

Le wagonnet est chargé de pierres vertes et reste dans la pente sans cale ni frein visible, conformément à la page actuelle `rails2`. Au sommet, les tours brisées restent lointaines et silencieuses, et la tablette apparaît parmi les rochers. Le Replat porte quatre pierres plates orientées vers le même horizon ; il ne contient pas de nid d’oiseau malgré son identifiant `nid`.

Les énigmes numériques précises restent portées par le texte du jeu, pas par le décompte des petits traits générés. Les PNG sources, les prompts exacts et les WebP sont conservés. Génération individuelle par l’outil intégré ImageGen, fond transparent, puis simple encodage d’export.

La page `index.html` est une planche artistique séparée de la production, sans accès à la sauvegarde. La Vue du Sommet et le Replat sont repliés. Voir les consignes d’intégration du lot `age-cuivre-v1` pour les identifiants actuels et anciens des fragments.
