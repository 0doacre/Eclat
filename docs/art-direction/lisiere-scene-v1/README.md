# Une terre, une scène

Prototype isolé après la suspension du monde panoramique. La production reste sur le Domaine en pages.

Une seule terre occupe le cadre. Les matières sont des zones de récolte sur le paysage, sans icônes déportées. Un appui récolte, un appui maintenu répète ; relâchement, annulation, fenêtre et sortie de l’application arrêtent le geste. Les lieux se sélectionnent dans la scène ; leurs études se collectionnent dans une page à part. L’atlas sert à changer de terre, sans empiler les paysages.

Parcours : Grand Chêne → Grotte aux Mains et Cercle de Pierres → sentier → aperçu de la Plaine → retour par l’atlas. Le prototype utilise les illustrations existantes. Le camp et les extracteurs ne sont pas encore intégrés. Les explorations durent trois secondes pour la démonstration ; aucune règle ni sauvegarde du jeu réel n’est utilisée ou modifiée.

À valider sur téléphone avant une intégration : cadrage, reconnaissance des matières, confort des cibles, découverte sans encombrement, transition entre terres. Aucun nouvel asset n’est requis pour cette étude de navigation.
