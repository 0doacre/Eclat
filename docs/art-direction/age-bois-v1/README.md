# Direction Artistique — Âge du Bois v1

Les ressources graphiques maîtresses produites pour l'Âge du Bois (Carnet du Semeur) sont conservées dans ce dossier.

> [!NOTE] Limite de taille Cloudflare Pages
> Cloudflare Pages impose une limite stricte de 25 Mo (26 214 400 octets) par fichier statique déployé.
> L'archive d'origine (29,2 Mo) a donc été scindée en deux archives indépendantes :
> - `da-age-bois-v1-part1.zip` (15,8 Mo)
> - `da-age-bois-v1-part2.zip` (12,0 Mo)

Les deux archives contiennent l'arborescence `da-age-bois-v1/` et peuvent être extraites dans le même dossier de destination pour reconstituer l'ensemble complet sans aucun outil particulier.
