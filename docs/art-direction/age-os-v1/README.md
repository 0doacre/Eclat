# Direction Artistique — Âge de l'Os v1

Les ressources graphiques maîtresses produites pour l'Âge de l'Os (Carnet du Semeur) sont conservées dans ce dossier.

> [!NOTE] Limite de taille Cloudflare Pages
> Cloudflare Pages impose une limite stricte de 25 Mo (26 214 400 octets) par fichier statique déployé.
> L'archive d'origine (26,4 Mo) a donc été scindée en deux archives indépendantes :
> - `da-age-os-v1-part1.zip` (14,0 Mo)
> - `da-age-os-v1-part2.zip` (11,3 Mo)

Les deux archives contiennent l'arborescence `da-age-os-v1/` et peuvent être extraites dans le même dossier de destination pour reconstituer l'ensemble complet sans aucun outil particulier.
