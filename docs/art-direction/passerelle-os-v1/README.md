# Âge de l’Os — La Passerelle

Le paysage de la Plaine, le Champ des Os, le Tumulus, les objets et curiosités sont déjà illustrés. Le chantier manquant est la Passerelle vers la Rivière Lente (`D.PASSAGES.riviere`, prérequis : outre). Le lore mentionne bois, cuir et os : pas de métal ni de maçonnerie.

Ce lot fournit trois images clés 1536 × 1024, alpha préservé : berges sans ouvrage, charpente partiellement couverte et passerelle terminée. PNG sources dans `masters/` ; encodages WebP, sans redimensionnement ni retouche, dans `assets/carnet/passages/`. Génération et variantes par l’outil intégré ImageGen ; seuls les encodages de fichiers sont effectués localement.

La page `index.html` permet de comparer les états sur le papier du jeu et dans le contexte des illustrations existantes. Aucune nouvelle interface de Domaine ni règle de jeu n’est introduite ; aucun accès à la sauvegarde. Les états sont des illustrations complètes, pas des calques précisément séparés : ne pas les présenter comme des couches indépendantes d’eau, de pieux et de tablier. Pour une animation fine, préparer ensuite ces éléments séparément à partir de cette composition validée.

Les variantes conservent le cadrage général, mais ne sont pas garanties identiques pixel par pixel. La séquence emploie des fondus entre images clés ; elle sert à valider la continuité artistique avant raccord aux apports réels.
