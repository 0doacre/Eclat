# La Rivière Lente — découvertes v1

Trois illustrations neuves pour les explorations existantes : le Gué (et son galet percé), la Carcasse et l’Escalier Noyé. L’eau vert-gris, les saules, les roseaux et les galets prolongent le paysage de rivière déjà dans le jeu.

La Carcasse suit le récit : machine d’entretien à six roues, bras replié, petit squelette d’oiseau dans sa pince. La plaque reste sans lettres dans le dessin ; son inscription appartient au texte du jeu. L’Escalier Noyé montre l’entrée sous l’eau, sans révéler dans cette vue la salle sèche ni son contenu.

Chaque image a été produite individuellement avec ImageGen intégré, sur fond transparent. PNG sources dans `masters/`, prompts exacts dans `prompts.json`, WebP dans `assets/carnet/discoveries/`. Aucun remplacement des fichiers existants.

La page `index.html` met les dessins en contexte sur le papier du carnet. Les deux découvertes ultérieures sont repliées. Il s’agit d’une planche artistique sans accès à la sauvegarde, séparée de la production. Voir le document d’intégration du lot `age-pierre-v1`.
