# Raccord de l’Acier

Les 11 exports utilisent les identifiants exacts du jeu. Les WebP sont livrés sous `assets/carnet/items/` à la racine du dépôt. Pour leur activation, raccorder le registre d’illustrations, les crédits, le manifeste et le cache dans une PR d’intégration distincte. Conserver les conditions de découverte existantes.

Ne pas inclure la brique réfractaire (déjà livrée avec le Fer), le piston ou la chaudière (Vapeur). Ne modifier aucune recette, valeur ou sauvegarde. Les PNG maîtres et les documents de revue ne doivent pas être ajoutés au cache de production.

Les choix et prompts de chaque illustration sont conservés dans `prompts.json`. La date de génération est le 30 octobre 2026 ; outil intégré OpenAI ImageGen, modèle précis non exposé. Exports avec Pillow. Droits d’utilisation soumis aux conditions OpenAI applicables aux images générées ; aucune licence tierce revendiquée.
