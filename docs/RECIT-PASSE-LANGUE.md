# Récit : passe sur la langue

Cette passe suit le retour de l’auteur : après plusieurs parties terminées, le récit reste
difficile à comprendre. Le travail porte sur les textes affichés, y compris ceux que l’auteur
garde volontairement dans le coffre. Ce document ne contient aucune révélation.

## Direction

Chaque lecture doit donner quelque chose à retenir : un fait, une observation, une tentative,
une contradiction précise. Le joueur garde à établir les liens entre les découvertes.

Les réécritures précisent les pronoms sans référent clair, remplacent les périphrases décoratives
et développent les notes trop elliptiques. Le motif des mains reste aux endroits où il sert
de repère, de dessin ou de geste ; il ne désigne plus indistinctement les personnes et le travail.
Les documents techniques expliquent leurs termes. Les voix gardent leurs différences.

## Périmètre

La passe concerne le Livre et ses marges, les fragments et leurs revisites, les feuillets,
les notes de nuit, les communications, les archives, les scènes et les textes de fin.
Quelques descriptions d’objets et réminiscences associées sont relues avec eux.

Les événements du récit, les conditions de découverte, les réponses, les signes et leurs airs,
les récompenses et les sauvegardes restent les mêmes. L’introduction appréciée par l’auteur
est conservée. Les archives d’une ancienne version du récit ne sont pas réécrites.

## Vérification

Comparer les données avec la base de la branche : seuls les textes affichés changent ; les
identifiants, conditions, nombres, réponses et paramètres interpolés sont conservés. Relancer
les parcours du récit et le contrôle mobile du Journal, du Livre et des scènes.

Les tests vérifient la cohérence et le rendu. La compréhension devra encore être observée
auprès de joueurs : ce travail ne suffit pas à affirmer que le mystère est désormais bien dosé.
Le détail de l’audit et les choix concernant l’intrigue restent dans `docs/coffre/AUDIT-LANGUE.md`.

Résultats de cette passe : 80 champs affichés réécrits, comparaison des données avec la base
sans changement des règles ni des jetons de signes et paramètres, `npm test` réussi (dont
60 tests du récit), 480 contrôles UX mobiles et 84 contrôles ciblés supplémentaires. Ces derniers
ouvrent les 32 pages du Livre, sept fragments et les archives à 320 px en texte normal et
390 px en grand texte, avec les signes inconnus puis compris. Aucun débordement horizontal
ni erreur JavaScript observés dans ces parcours.
