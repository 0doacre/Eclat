# Filtrer les matières étudiées par geste

28 octobre 2026.

Dans l'Atelier classique, **Filtres → À découvrir** garde uniquement les matières étudiées qui participent à une recette encore inconnue avec le geste choisi. Le compteur suit ce geste. Les filtres **À tenter** (tous les gestes) et **Action** (recettes connues) restent disponibles. Les filtres apparaissent dès la première matière étudiée, sans attendre huit matières vues.

Le filtre reprend l'information de l'étude : les autres ingrédients doivent avoir été vus et le geste être ouvert. Il ne révèle ni noms ni recettes supplémentaires, ne consomme rien et n'affirme pas que les stocks ou la chaleur suffisent à fabriquer. Les matières déjà vues mais épuisées peuvent rester visibles, comme dans les autres filtres classiques.

Dans la preview, la case **À découvrir** sous la recherche porte sur le poste, l'outil et son mode exact. Couper et Entailler sont distincts ; les modes du feu et du four aussi. Le menu **Geste** permet de changer ce mode sans lancer d'essai. Le bouton **Étudier les matières** dépense le coût d'Intuition affiché uniquement sur clic explicite.

La recherche se combine au filtre ; une recette découverte retire immédiatement les pistes devenues inutiles. Changer de filtre, de geste ou d'outil conserve les matières déjà posées sur l'établi. Le filtre est mémorisé dans la sauvegarde. Un état vide indique comment retrouver des pistes.

Validation : tests des réactions et de la sauvegarde ; parcours navigateur en 320, 390 et 980 px sur les deux ateliers, avec changement de geste, découverte, étude, recherche et rechargement.
