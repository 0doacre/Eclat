# Crédits

## Icônes

Les icônes du jeu viennent de [game-icons.net](https://game-icons.net), sous licence
[Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/) (CC BY 3.0).
Elles sont récupérées via l’API [Iconify](https://iconify.design) (collection « Game Icons »)
et assemblées dans `assets/icons.svg` par `node tools/icons.js` (correspondance dans `tools/icons.json`).

Icônes : game-icons.net — Lorc, Delapouite et les contributeurs, CC BY 3.0.

Les icônes ont été recolorées (`currentColor`) et redimensionnées ; leur dessin n’a pas été modifié.
Dépôt source : <https://github.com/game-icons/icons> (les fichiers y sont rangés par dossier d’auteur).

## Grands Œuvres et fonds d'écran
